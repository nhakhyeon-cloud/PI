# 남성 패션 상세페이지 생성기

> 무신사 · 29CM 스타일의 프리미엄 남성 패션 상세페이지를 자동으로 생성하는 웹 애플리케이션

## 🚀 실행 방법

```bash
npm install
npm start
# → http://localhost:3000
```

## ✨ 주요 기능

### 4단계 입력 폼
| 단계 | 내용 |
|------|------|
| Step 1 | 브랜드명, 상품명, 카테고리, 가격, 소재, 핏, 사이즈 |
| Step 2 | 메인/상세/스타일 이미지 업로드 (드래그&드롭) |
| Step 3 | 상품 설명, 스타일 가이드, 세탁 안내, 검색 태그 |
| Step 4 | 요약 확인 후 상세페이지 생성 |

### 생성되는 상세페이지 구성
- 이미지 슬라이드 갤러리 (썸네일 + 메인 + 터치 스와이프)
- 상품명, 브랜드, 가격 (할인율 자동 계산)
- 사이즈 선택 / 수량 조절 / 장바구니 · 구매 버튼
- 상세이미지 / 사이즈 가이드 / 구매정보 탭
- 세탁 안내, 스펙 테이블, 스타일 가이드
- 모바일 반응형 레이아웃

### 내보내기
- 실시간 PC/모바일 미리보기
- HTML 코드 복사
- HTML 파일 다운로드

## 🛠️ 기술 스택
- **Backend**: Node.js, Express.js, Multer
- **Frontend**: Vanilla JS, CSS3 (Noto Sans KR)
